# Art & Beleza — website

Site de uma página do cabeleireiro Art & Beleza (Ferreiras, Albufeira). Português e inglês.

- Publicado com GitHub Pages: https://valerialazarinfo-lab.github.io/art-beleza/ (cada push a `main` atualiza o site).
- Tudo está em `index.html` (HTML, CSS e JavaScript juntos). Sem build nem dependências.
- Imagens em `img/`; `img/partilha.jpg` é a pré-visualização em redes sociais.
- Contacto principal: WhatsApp/telefone definidos em `index.html`.

## Regras para alterações
- Testar no telemóvel antes de enviar para `main` — o site é público.
- Manter as duas línguas sincronizadas.
- Só usar fotografias e contactos autorizados pela cliente.
